# 微型商家單頁網站 RWD 修復案例

這是一個以「既有靜態網站修復」為情境的教學作品。專案保留修復前與修復後版本，用來展示問題重現、原因判斷、修改內容與驗收方式。

## 專案結構

```text
before/  修復前故障
after/   修復後
CHANGELOG.md
TEST_REPORT.md
```

開啟方式：分別雙擊 [查看修復後版本](https://raven03115.github.io/rwd-repair-case/) 與 [查看修復前版本](https://raven03115.github.io/rwd-repair-case/before/)，即可比較修復前後差異。

## 原始問題

1. 手機版選單按鈕沒有反應，Console 出現 JavaScript 錯誤。
2. 商品卡片使用固定欄寬，在手機與平板產生水平溢出。
3. 詢價表單與按鈕使用固定寬度，造成窄螢幕頁面超出 viewport。
4. 圖片被固定高度拉伸，比例失真或構圖不合理。

## 修復內容

- 將 JavaScript 選擇器改為與 HTML 實際 class 一致。
- 商品網格改為彈性欄寬，並依 900px、760px 斷點切換三欄、兩欄、一欄。
- 表單改用 `width: 100%` 與 `max-width`，平板以下改為單欄配置。
- 主視覺使用自動高度保持完整比例；商品圖片使用 `object-fit: cover` 維持卡片整齊。
- 保留表單送出提示與手機導覽展開／收合功能。

## 技術範圍

- HTML5
- CSS Grid、媒體查詢、響應式寬度
- 原生 JavaScript DOM 與事件處理
- Edge 開發者工具與 Console

## 專案限制

- 純靜態示範網站。
- 表單只顯示前端提示，不會寄送電子郵件。
- 不含登入、付款、資料庫、後端與正式主機部署。

## 實作歸屬

主要修復由學習者依逐步提示操作並以 Edge 驗證。審閱版另由工具修正一項輸入錯誤：送出按鈕的 `width: 100px` 改為原規格的 `width: 100%`；此項不視為學習者獨立完成的能力證據。
